# 2026 Settings Design Archive

This directory preserves the iteration log of the 2026 settings redesign,
inherited from the upstream project: the rubric scores, the parent reviews, the
research notes and the measured contrast samples.

It is a closed record, not a list of current rules. Some of its values have
since changed in the code (for example the Settings window's default size and
the primary button's shades). Where it disagrees with the code, the code wins.

Current design rules for the whole app, overlays and settings alike, live in
[`../../DESIGN_BOOK.md`](../../DESIGN_BOOK.md).
